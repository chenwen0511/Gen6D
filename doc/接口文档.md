# Gen6D REST API 接口文档

Base URL: `http://<host>:8000`

启动服务（推荐）：

```bash
cd /home/ubuntu/stephen/01-code/Gen6D
bash start.sh restart
# 或
# GEN6D_PYTHON=.../gen6d/bin/python python run_server.py --host 0.0.0.0 --port 8000
```

入口：

- **Gradio UI**: `http://localhost:8000/ui`（深度估计 / 抓取 位姿估计 / 融合深度+SAM-6D）
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

抓取点 `q` REST：`POST /api/v1/infer/grasp`（或 `/infer/grasp`），见 [grasp_api.md](grasp_api.md)。  
算法说明见 [sam3_seg_tab.md](sam3_seg_tab.md)，也可在 UI Tab 内完成。

## 上传图像推理

**POST** `/api/v1/depth/predict`

Content-Type: `multipart/form-data`

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `rgb` | file | 是 | RGB 图像（png/jpg） |
| `depth` | file | 否 | 传感器深度图（uint16 png 或灰度图） |
| `intrinsics` | string | 否 | 相机内参 JSON 字符串（UI 端可上传 `.json` 文件，格式相同） |

### intrinsics JSON 格式

```json
{
  "cam_K": [
    393.12, 0.0, 322.45,
    0.0, 392.81, 242.94,
    0.0, 0.0, 1.0
  ],
  "depth_scale": 1.0
}
```

- `cam_K`: 3×3 相机内参矩阵（行优先 9 个数）
- `depth_scale`: 深度缩放系数，默认 1.0

### 响应示例

```json
{
  "depth_shape": [504, 378],
  "depth_range": [0.3373, 1.9810],
  "conf_range": [1.0, 1.8192],
  "sensor_valid_ratio": 0.7761,
  "sensor_depth_range": [84.0, 3141.0],
  "point_count": 50000,
  "session_dir": "/home/ubuntu/stephen/01-code/Gen6D/outputs/sessions/20260712_110530",
  "images": {
    "processed_rgb": "<base64 PNG>",
    "pred_depth_vis": "<base64 PNG>",
    "conf_vis": "<base64 PNG>",
    "sensor_depth_vis": "<base64 PNG>"
  },
  "pointcloud": {
    "point_count": 50000,
    "glb_url": "/files/pointclouds/abc123.glb",
    "ply_url": "/files/pointclouds/abc123.ply"
  }
}
```

点云文件通过 URL 下载，不在 JSON 中传输点坐标。默认降采样至 **5 万点**。

### 会话归档（session_dir）

每次推理会自动将上传数据与结果保存到 `outputs/sessions/<timestamp>/`，便于回溯：

| 文件 | 说明 |
|------|------|
| `rgb.png` / `rgb.jpg` | 用户上传的 RGB 原图 |
| `depth.png` | 用户上传的传感器深度（uint16 原文件） |
| `camera.json` | 相机内参 |
| `meta.json` | 会话元信息（时间、来源 ui/api） |
| `processed_rgb.png` | 模型预处理后 RGB |
| `pred_depth_vis.png` | 预测深度可视化 |
| `fused_depth_vis.png` | 融合深度可视化（有 depth 时） |
| `conf_vis.png` | 置信度可视化 |
| `sensor_depth_vis.png` | 传感器深度可视化 |
| `pointcloud.glb` / `pointcloud.ply` | 点云文件副本 |
| `summary.json` | 推理摘要 |

响应字段 `session_dir` 为本次会话目录绝对路径。

### curl 示例

```bash
curl -X POST "http://localhost:8000/api/v1/depth/predict" \
  -F "rgb=@rgb.png" \
  -F "depth=@depth.png" \
  -F 'intrinsics={"cam_K":[393.12,0,322.45,0,392.81,242.94,0,0,1],"depth_scale":1.0}'
```

## 错误码

| HTTP 状态码 | 说明 |
|-------------|------|
| 400 | 请求参数错误或图像格式无效 |
| 500 | 模型推理失败 |

### 错误响应示例

```json
{
  "detail": "Invalid RGB image: ..."
}
```

## 图像字段说明

响应中 `images` 下所有字段均为 **Base64 编码的 PNG**：

| 字段 | 说明 |
|------|------|
| `processed_rgb` | 模型预处理后的 RGB |
| `pred_depth_vis` | 预测深度伪彩色图 |
| `conf_vis` | 置信度伪彩色图 |
| `sensor_depth_vis` | 传感器深度伪彩色图（上传 depth 时返回） |
| `fused_depth_vis` | 融合深度伪彩色图（上传 depth 时返回） |

### fusion 字段（上传 depth 时返回）

| 字段 | 说明 |
|------|------|
| `status` | `success` / `fallback_*` |
| `scale`, `shift` | 对齐参数 |
| `align_inlier_ratio` | RANSAC 对齐 inlier 比例 |
| `sensor_valid_ratio` | 传感器有效像素比例 |
| `fused_valid_ratio` | 融合后有效像素比例 |
| `inpaint_ratio` | 估计深度补全区域比例 |

### pointcloud 字段

| 字段 | 说明 |
|------|------|
| `point_count` | 降采样后点云点数（默认最多 5 万） |
| `glb_url` | GLB 文件下载地址，适合浏览器 3D 预览 |
| `ply_url` | PLY 文件下载地址 |

点云通过文件 URL 下载，不在 JSON 中传输点坐标，单帧 GLB 约 **0.8 MB**（5 万点）。

## UI 演示

UI 与 API 共用 **8000** 端口（避免 7861 等端口被网络拦截）：

```bash
conda activate gen6d
cd /home/ubuntu/stephen/01-code/Gen6D
bash start.sh restart
```

| 页面 | 地址 |
|------|------|
| **Gradio UI** | http://\<host\>:8000/ui（深度估计 / 抓取 位姿估计 / 融合深度+SAM-6D） |
| **API 文档** | http://\<host\>:8000/docs |

SAM3 抓取点说明：[sam3_seg_tab.md](sam3_seg_tab.md)。

也可单独启动 UI（本地调试，默认 7860 端口）：

```bash
python run_UI.py --host 0.0.0.0 --port 7860
```
